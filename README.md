Kleine Dieben es un videojuego de aventura gráfica "point-and-click", rompecabezas y sigilo. Este seria de plataforma para PC.

Este tendrá un estilo de animación estilo “Cutout Animation’’ donde este tendrá un estilo de teatro de marionetas o sombras, y estará animado en 2D.

Los personajes tendrán un estilo caricaturesco y minimalista, donde tendrán proporciones exageradas y cómicas.

Sus mecanicas principales serian correr/andar, coger, esconderse, bajar, salir y entrar

Este juego seria desarollado por Unity
